# 선정된 원기둥 환경 평가 — 사용자 결정 (2026-09-15)

## 연구 범위와 유지 조건

사용자는 알고리즘·planner를 수정하지 않고 원기둥의 배치·배열·크기만
변경해 모드 간 결과 차이가 나타나는 Stress 맵을 찾기로 결정했다.
논문 범위는 선정된 정적 시뮬레이션 환경이며, 다른 환경이나 실제 비행으로
일반화하지 않는다. Normal 5맵과 Stress 5맵에서 Full/Sector/Adaptive를
맵·모드당 20회 비교하는 구성은 총 600회다. 이 숫자는 논문 구성 목표이며
현재 완료 횟수가 아니다. 기존 Normal의 재사용 가능성은 버전과 계측 기준의
일치 여부를 별도로 확인해야 한다.

Stress 선정 기준은 각 맵의 새 20회에서 Full과 Adaptive 각각 20/20 완주와
관측 접촉 0, Sector는 실제 완주 실패 또는 실제 접촉이 한 번 이상 있는
것이다. 개발 3묶음은 이 20회에 합산하지 않는다. 기존 실행기는 확인 중
기준모드 실패 시 해당 3모드 묶음까지 마친 후 조기 중단·후보 제외한다.
이런 실행은 20회 완료로 표시하지 않는다.

**20회 결과 자체를 보고 통과 맵을 선택하는 결과 의존적 탐색**이다.
디렉터리의 `confirmation_n20` 명칭과 무관하게, 최종 선택된 맵의 100%를
선택 편향 없는 모집단 성공률이나 독립적인 환경 일반화 증거로 해석하지
않는다. 탐색 후보 수·탈락 이유·중단 규칙을 함께 공개한다. 세 모드의 접촉이
모두 0이면 입증한 차이는 완주성이지 충돌 예방 우위가 아니다.

계속 유지한다. 이미 구현된 retry 경로를 켜는 것 역시 실행 정책 변경이므로
이번 map-only 탐색에는 적용하지 않는다.

종료됐다. 이 실패들을 맵 난도에 의한 실패로 단정하지 않는다. J07에서 최초
누락된 스캔이 어느 전달/처리 단계에서 빠졌는지는 기존 로그만으로 확정되지
않았다. 재요청이 꺼진 exact-ACK 대기 구조는 코드와 최종 통계로 확인했다.
성공 맵을 선정해도 이 공통 실행 한계가 해결되거나 재발 불가능해지는 것은
