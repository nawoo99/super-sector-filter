# C23 Normal 5맵×3모드×5회 비교 (2026-09-16)

## 사전 명시한 범위

최신 사용자 요청: Full/Sector/Adaptive, 5개 맵, 각5회 실행 및 맵별 표와 예상시간.
N1–N5는 seed1/3/5/7/9. 이번 본시험은75회이며 n20로 자동 확장하지 않는다.
예상 소요시간은 준비/사전점검/집계 포함 약1시간40분–2시간이라고 안내했다.
시작 시각은 status.json/plan.json에 기록한다.

C22 iteration04의 코드·맵·바이너리를 그대로 사용한다. 공통 side worker3,
dispatch lease0.25초, event Adaptive body-heading opt-in ON. 기본옵션은 변경하지 않는다.
현재 Full은 수정/최적화된 guarded SUPER이며 원본 논문 구현 그대로라는 주장은 하지 않는다.

## 이전 중단과 이번 비교의 차이

C22는 모든 쌍에서 Adaptive 시간이 Full의1.10배 이내여야 하는 최적화 합격시험이었다.
이번 요청은3모드 비교시험으로 해석하고, 시작 전 시간차가10%를 넘어도 기록하며
중단하지 않겠다고 안내했다. 기존 실패 판정/원자료는 그대로 보존한다.
측정 실행기의 새 `--mission-time-as-metric`은 시간비를 여전히 기록하되
소형 worker pool 사전점검 수락에서만 시간 성능 조건을 제외한다. 기본값은 기존 엄격 동작.
센서/정적전달/복구/주기/속도/자원/바이너리 일치 조건은 완화하지 않는다.
유효한 미완주/접촉은 결과에 남기며 성공 회차로 대체하지 않는다. 측정/계약 오류는 중단한다.

정적 전달/RViz 5맵 기존 증거의 현재 해시를 재검증한다. 같은 런타임의 N1–N4 ON12회는
보조 주기 증거로만 재사용하고, 아직 없는 N5 ON3회를 추가한다. ON은 본시험 CPU 통계와 분리.
이후 OFF75회는 새 독립 표본이다. 맵 순서와 모드 순서를 순환하고 자동재시도하지 않는다.
기존 Normal/실패 진단/새 비교 데이터는 합치지 않는다.

## 기록 범위와 해석

- 완주, 접촉/최소간격, 시간, 경로 길이, 속도와 자원 품질.
- 실험 cgroup CPU 평균/누적(core-s), 컴퓨터 전체 용량 대비 %, 배경 포함 host CPU/baseline.
- RSS/PSS/swap/PSI, GPU 장치 전체 관측값.
- 맵 갱신/raycast 경과시간, 포인트, 논리 payload, 소스/odom 주기와 간격.
- Adaptive 시야 전환/Full 복구 진입/인증 완료 횟수.
- 개별 callback CPU 시간/실제 FSM 주파수는 별도 ON 증거; OFF 미측정은 N/A.

실험 CPU에는 시뮬레이터가 포함된다. GPU는 프로세스별 귀속값이 아니고,
논리 payload는 물리 네트워크/PCIe 대역폭이 아니다. 누적CPU의 측정구간은 주행시간보다 넓다.
원래 평균CPU40% 목표를30%로 소급 변경하지 않는다. 상대 감소율은 실제 관측값 그대로 보고한다.

### N3 Adaptive 메모리 급증 (run16112, attempt1)

FSM/planner의 진행 로그가 멈췄다. 메모리가 동시에 증가했지만 종료 후라 stack은 미확보이다.
정확한 원인 함수는 미확정이다. 동기 계획의 무한/장시간 루프나 보존량 증가를 조사해야 한다.

이 추측을 수정 완료/근본 원인 확정으로 기록하지 않는다.
